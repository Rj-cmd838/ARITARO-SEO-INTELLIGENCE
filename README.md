# ARITARO SEO Intelligence

AI-powered SEO Intelligence SaaS platform.

## Project Overview
A platform designed to provide:
- Technical SEO audits
- On-page SEO analysis
- Website crawling
- Keyword intelligence
- Competitor analysis
- AI-powered SEO recommendations

## Technology Stack
- Frontend: Next.js + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL
- AI: Gemini / OpenAI

## Backend Development
Backend development is handled using Python and FastAPI.
